
# Order Summary Screen Mini-Spec

1. Inputs: Item name, quantity, and unit price.
2. Output: Display item name, quantity, and total price.
3. Rules: Calculate total using orderTotal().
4. UI: Show order details in a clean Flutter screen.
5. Out of Scope: No payment or checkout functionality.
6. Check: Verify that 2 items at RM12.50 each total RM25.00.
